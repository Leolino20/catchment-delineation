# Teaching DEM

`seyon_valangin_dem_eudem25.tif` is a 25 m resolution DEM subset covering the
Seyon catchment and its surroundings near Valangin, Switzerland.

## Raster properties

- format: GeoTIFF, 32-bit floating point;
- coordinate reference system: ETRS89 / LAEA Europe (`EPSG:3035`);
- cell size: 25 m;
- dimensions: 1,053 columns by 941 rows;
- role: input data for the WhiteboxTools teaching workflow.

The subset is intentionally larger than the expected catchment so that the
upstream divide is not imposed by the raster edge.
